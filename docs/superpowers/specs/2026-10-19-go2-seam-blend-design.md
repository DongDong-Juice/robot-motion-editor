# GO2 이음매 자동 보정 (seam blend)

## 배경

라이브러리 블럭(실제 GO2 로그)과 Empty를 타임라인에 이어 붙여 동작을 조합한다. 블럭마다 시작·끝 서 있는 자세가
조금씩 달라(관절 11~27°, 높이 1~3 cm) 조각이 바뀌는 프레임에 자세가 툭 튄다. 기본자세·전이·관성(리드인)은
블럭 조합에 맞지 않고, 블럭 CSV는 고치지 않는다(사용자).

## 결정 (사용자 확정)

- GO2만. G1은 지금처럼(리드인·끝 기본자세).
- 항상 켜짐. 길이 기본 20프레임, 레인에서 끌어 조절.
- 블럭 CSV·조각 길이는 그대로(프레임이 늘지 않음).

## 동작

- 대상: 같은 트랙에서 앞 조각 끝 = 뒤 조각 시작(간격·겹침 없음)인 GO2 조각 쌍. 겹치면 기존 크로스페이드, 간격이면 보정 없음.
- 뒤 조각 앞 N프레임에 차이를 더하고 0까지 줄임(inertialization):
  - d0 = (앞 끝 자세 + 앞 끝 속도) − 뒤 첫 자세, v0 = 앞 끝 속도 − 뒤 첫 속도 (프레임당).
  - offset(k) = d0·(2s³ − 3s² + 1) + v0·N·(s³ − 2s² + s), s = k/N, k ∈ [0, N). k ≥ N은 0.
  - 채널: 관절, root.z, root.roll, root.pitch (roll/pitch 차이는 ±π로 감음). x·y·yaw는 기존 루트 이어붙이기.
  - 관절은 URDF 한계로 자름.
- `itemClip`에 넣음 → 메인 재생·클립 프리뷰·조각 CSV·물리·리드인이 모두 같은 값(미리보기 = CSV).
  편집기(인스펙터·그래프·기즈모)는 `editedClip`(보정 전)을 그대로 씀.
- 길이: `Item.seam`(프레임, 없으면 20, 0~180, 조각 길이까지). 레인에서 뒤 조각 막대 앞쪽 `이음` 블록(`--blend` 색)의
  오른쪽 경계를 끌어 조절, 놓을 때 한 번 저장(실행취소 1번).
- 경고: 관절 차이 45° 초과 또는 높이 차이 5 cm 초과면 블록 라벨 `이음 ⚠` + 도움말(앉은·누운 끝 → 서기 등).

## 남은 위험

- 관절만 맞추므로 서 있는 발 위치가 다르면 보정 동안 발이 조금 미끄러질 수 있음(필요하면 다음 단계에서 IK).

## 구현 계획

1. `types.ts` `Item.seam`, `projectFile` 검증, 스토어 `setRestLead`에 `seam` 추가.
2. `model/seam.ts`: `seamOf(p, defs, it)`(앞 조각·N·d0·v0·경고), `itemClip`에서 프로젝트별 캐시로 적용.
3. `SequenceCanvas`: `이음` 블록 그리기·라벨·경계 끌기(기존 리드인 블록 끌기와 같은 방식).
4. 테스트: seam 단위(연속성·N 이후 원본·G1 미적용·간격 미적용·캐시), 스토어 길이 조절, e2e 레인 끌기.
