# 자르기 끝 기본자세 (2026-10-14)

사용자 요청: "자르기할때마다 기본자세 뒤쪽에 0.5초 넣어줘 — #1에서 #2로 자르면 #1 끝·#2 끝에 기본자세, #2에서 #3으로 자르면 #2는 이미 있으니 #3만 추가."

## 동작

- 자르기(`C`, 시퀀스 상단 `자르기` 버튼) = `splitItem`: 모션 트랙이면 왼쪽 조각 `restTail ??= true`, 오른쪽 조각 `restTail = true`.
  - 사용자가 끈 조각(`restTail: false`)은 다시 잘라도 왼쪽은 꺼진 채로 둔다. 새로 생긴 오른쪽 조각만 켠다.
- 끝 기본자세 = 조각 마지막 프레임 뒤에 **전이(자동) → 차렷 정지 0.5 s(30프레임)**.
  - 끝 프레임에서 차렷으로 순간이동하지 않게 하려고 전이를 넣는다. 전이 길이는 덧붙이기 `'auto'`와 같은 규칙(관절 속도 한계 50%, 걸음 시간)으로 정한다.
  - 구현: 조각 끝 최대 240프레임을 거꾸로 재생한 클립에 `prependRestPose`(덧붙이기 리드인)를 적용하고, 결과를 다시 뒤집는다(`appendRestPose`).
  - 따라서 리드인과 같은 성질을 가진다. 루트 x·y·yaw는 마지막 프레임 값에 고정(드리프트 없음), 다리는 IK로 한 발씩 디뎌 미끄러지지 않는다.
- 덧붙이기 리드인처럼 **클립 프리뷰와 그 조각 CSV에만** 반영한다(CSV 끝에 행 추가, `restTailRows`). 메인 타임라인 재생은 원본 그대로.
- 시퀀스 레인: 조각 막대 바로 뒤에 `전이`(`--blend`)·`기본자세`(`--rest`) 블록. 한 줄로 접으면 얇은 띠. 레인 라벨 호버에 "끝 기본자세".
- 클립 프리뷰 `끝 기본자세` 버튼(aria-pressed)으로 조각마다 켜고 끈다(`setRestTail`, 실행취소 1, 잠금 거부). 프로젝트에 저장(`items[].restTail` boolean).

## 검증

- 단위: `store.test.ts`(자르기 규칙·저장·검증), `csv.test.ts`(행 수·마지막 0.5 s = 차렷·드리프트 없음).
- 회귀: `src/model/restTail.sweep.test.ts` — Track1을 400프레임마다 끝내고 미끄러짐·가라앉음·공중 정지·관절 속도·드리프트·마지막 차렷을 확인한다. 끝에서 발이 떠 있으면 내려놓는 동안 공중 대기를 15프레임까지 허용.
