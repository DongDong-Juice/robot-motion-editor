# 부위 얹기 1차 (A 범위) · 사용자 블록

- 날짜: 2026-11-09
- 상태: 승인됨 · 1차 구현됨 (수정변동사항.md §26)
- 기반: §19 발 걸음 이음매 · §20 걷기 블록 · §22 안정성 우선 · §23 추천 수정 · §25 미리보기 = 실제

## 1. 목적

행동 블록 위에 다른 블록의 **일부 부위 움직임**을 얹는다. 예: 앞다리를 든 자세 위에 앞다리 교차 · 위아래 흔들기,
G1 다리 동작 위에 팔 동작. 결과는 시퀀스의 그 조각 한 군데에 쓰거나, 새 **사용자 블록**으로 저장해 다시 쓴다.

## 2. 확정 사항 (사용자, 2026-11-09)

- 1차 범위 = **A(공중에 있는 부위)만**. 받치는 부위를 들게 되는 경우(B)의 몸통 보정은 보류.
- B 범위에 드는 경우는 **사유만 표시하고 막지 않음**(실기와 시뮬의 차이를 고려).
- 물리 한계(관절 한계 · 속도 · 바닥 뚫림 · 부위 충돌 · GO2 hip 54°)는 막음(§22), 사용자 블록은 IndexedDB(사용자 확인).
- 로봇 = **GO2 · G1 둘 다**.
- 적용 = **시퀀스 한 군데(조각)** + **새 사용자 블록으로 선언 · 저장**.
- 사용자 블록 저장 = **이 브라우저(로컬)에만**. 지워질 수 있음(사이트 데이터 삭제 · 다른 PC · 시크릿 창). 서버 저장은 서버 쪽과 합의 후.

## 3. 그동안 바뀐 내용에서 가져오는 원칙

- 안정성 우선(§22): 물리 한계를 넘는 결과는 적용하지 않고 이유 + 해결 버튼. 다른 편집으로 간접적으로 한계 초과가 되면
  얹기를 끄고 원래 블록 동작으로 재생(무너진 자세를 만들지 않음), 빨강 표시, 내보내기 막음.
- 시간은 바꾸지 않음: 조각 길이 그대로.
- 설정값으로 저장, 결과는 계산(§20 걷기와 같음): 다시 고칠 수 있고 판정도 매번.
- 미리보기와 적용은 같은 계산 하나(§25).
- 걷기 조각에는 얹지 않음(걷기는 순수 이동).
- 경계(§19 · §23): 얹은 결과로 이음매 · 발 걸음 이음매를 계산. 끝 자세가 바뀌면 뒤의 걷기 · 경계까지 판정.

## 4. 데이터

- `Item.overlays?: Overlay[]` (모션 트랙의 조각, 걷기 조각 제외)
- `Overlay = { id, src: 클립 ID(같은 로봇, 이 프로젝트 목록), srcA, srcB(원본 클립 프레임), at(조각 클립 프레임), len(프레임),
  parts: 부위 이름[], mode: 'replace' | 'add', weight: 0~1, fade: 앞뒤 섞임 프레임, loop: boolean }`
  - 부위: GO2 `FL` `FR` `RL` `RR`, G1 `왼팔` `오른팔` `허리` `왼다리` `오른다리`(로봇 정의의 부위 그대로).
  - 라이브러리 블록을 원본으로 고르면 목록에 같은 블록이 없을 때만 넣고(지금 블록 추가와 같음) 그 클립을 가리킴 → 프로젝트 파일만으로 재현됨.
- 층 순서: 원본 → 클립 수정 층 → **얹기** → 조각 수정 층(키 추가 · 슬라이더로 세밀 수정) → 이음매 보정 · 발 걸음 이음매.
  조각 수정 층의 "밑값"은 얹은 결과(슬라이더 값 = 보이는 값).
- 관절만 얹음. 몸통(루트)은 바탕 블록 그대로.

## 5. 계산

- 덮어쓰기: 그 부위 관절 = 원본 값. 더하기: 바탕 + (원본(t) − 원본(srcA)).
- 세기 `weight`, 앞뒤 `fade` 프레임은 smoothstep으로 0 ↔ 1.
- 반복 `loop`: `len`이 원본 구간보다 길면 되풀이. 이음새(끝 → 처음)도 속도 판정에 들어감.
- 관절 한계를 넘으면 자르지 않고 판정에서 걸림(조용히 모양이 바뀌지 않게).

## 6. 판정

| 구분 | 내용 | 처리 |
|---|---|---|
| 빨강(적용 안 함) | 관절 한계 넘음 · 관절 속도 모터 한계 1.0배 초과 · 발/손이 바닥을 1 cm 넘게 뚫음 · 부위끼리 충돌(5 mm 기준) · GO2 hip 54° 초과 | 적용 거부 + 해결 버튼 |
| 주황(적용, 표시) | 관절 속도 0.8배 초과 · 관절 가속 실기 최대치 초과 · GO2 hip 48° 초과 | 표시만 |
| 주황 · B 범위(적용, 표시) | 바탕에서 바닥을 딛던 발/손이 뜨거나 뜬 것이 닿음 · (무게중심이 받침 밖 — 1차 미구현, MuJoCo 확인 때) · 원본과 바탕의 몸 기울기 차이 15° 넘음(다리 방향이 달라짐) | "B 범위 — 몸통 보정은 아직 없음, 실기·시뮬 차이를 고려해 막지 않음" 표시만 |

- 해결 버튼(누르면 설정 칸 값만 바뀜): `세기 N%로`(통과하는 가장 큰 세기), `섞임 N프레임으로`(통과하는 가장 짧은 섞임), 둘 다 없으면 구간 · 부위를 바꾸라는 안내.
- 충돌: G1은 검수 목록의 충돌 검사 그대로. **GO2 다리끼리 충돌 검사는 새로 추가**(앞다리 교차에 필요).
- 판정 대상은 얹은 구간 ± 섞임 프레임, 끝 자세가 바뀌면 뒤 경계 · 걷기까지(§23 연쇄).
- 넘어지는지는 MuJoCo로 확인(PC는 학습 중인지 먼저 확인).

## 7. 사용자 블록

- 선언: 조각 우클릭 `사용자 블록으로 저장…` · 클립 편집 머리줄 `사용자 블록으로 저장` → 이름 → 그 조각(클립)이 재생하는 프레임을
  그대로 굳힌 클립(얹기 · 수정 층 포함, 기본자세 · 이음매 제외).
- 보관: 이 브라우저 IndexedDB. 라이브러리 `사용자 블록` 폴더(도움말 · 설정 칸에 "이 브라우저에만 저장" 안내)에 보이고 고정 블록처럼 끌어 놓기 · 우클릭으로 넣음
  (넣을 때 목록에 복사 → 프로젝트 파일로 재현). 우클릭 `이름 바꾸기` · `삭제`.
- 판정이 빨강인 조각은 사용자 블록으로 저장하지 않음.
- 저장 위치 안내: "이 브라우저에만 저장됩니다. 사이트 데이터를 지우거나 다른 PC에서는 보이지 않습니다."

## 8. 화면

- 인스펙터(조각 선택): `얹은 동작` 칸 — 얹은 것 목록(부위 ← 원본 · 방식 · 세기 · 구간 · 상태색), `+ 부위 얹기`.
  설정: 원본 블록(목록 + 라이브러리, 같은 로봇), 원본 구간, 부위, 방식, 세기, 얹을 위치 · 길이 · 반복, 섞임. 상태 · 이유 · 해결 버튼, `적용`.
- 타임라인: 조각 막대 아래쪽에 얹은 구간 띠(상태 색), 레인 도움말에 상태.
- 3D: 얹기 전 동작 고스트(원본 겹쳐 보기 재사용).

## 9. 범위 밖 (이번에 안 함)

- B 범위 몸통 보정(받치는 발을 들 때 몸 기울기 · 높이 맞추기), 원본/바탕 기울기 차이 보정.
- 클립(에셋) 단위 얹기, 사용자 블록 서버 저장 · 파일 내보내기, 걷기 조각 위 얹기, 몸통 얹기.
- new_rl "합성 구간 표시"(나중에 한 번에 정하는 질문 목록에 추가).
