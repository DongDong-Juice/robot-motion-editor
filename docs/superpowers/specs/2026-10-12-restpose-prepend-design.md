# 기본자세 덧붙이기 (설계)

날짜: 2026-10-12 · 상태: 합의됨 (사용자: "둘 다 제공", 길이 90프레임)

## 문제

기본자세 세팅은 조각 앞 1.5 s(유지 0.5 s + 블렌드 1 s)를 **덮어써서** 원래 모션의 앞부분이 사라진다. 원본 모션을 한 프레임도 잃지 않는 방식이 필요하다.

## 결정

- 두 방식을 모두 제공한다.
  - **덮어쓰기**(기존): 길이 유지, 앞 최대 90프레임을 기본자세 → 모션 블렌드로 바꿈.
  - **덧붙이기**(새): 조각 앞에 90프레임(유지 30 + 블렌드 60)을 **추가**. CSV가 90행 길어지고 원본 프레임은 그대로.
- 저장: `Item.restPose?: true | 'prepend'` (`true` = 덮어쓰기). 기존 파일·기존 앱과 호환.
- 적용 범위는 지금과 같다: 클립 프리뷰와 그 조각의 CSV(및 그 CSV로 하는 물리 검증)만. 타임라인 재생·조각 길이는 원본.

## 덧붙인 90프레임의 내용

- 시작 자세 R: 로봇별 기본자세(차렷) `def.rest.q`, `root.z` = `def.rest.z`(그 자세로 바닥에 닿는 높이), roll·pitch 0, x·y·yaw = 조각 첫 프레임 값. (처음엔 관절 0이었으나 G1 팔꿈치 0 = 팔을 앞으로 든 자세라 아래 '기본자세 = 차렷' 참고.)
- k = 0..29: R 유지. k = 30..89: smoothstep((k−30)/60)으로 R → 첫 프레임 자세(고정)로 채널별 보간. k = 90부터 원본.
- 클립 공간에서 파생 클립(`prependRestPose`)으로 만든다. 프리뷰는 이 클립을 `[trimIn, trimOut+90)`로 재생.
- CSV: 원본 조각 프레임은 지금처럼 `evaluate`로 뽑고, 앞 90프레임은 파생 클립 포즈를 첫 프레임 기준 평면 변환(xy·yaw)으로 월드에 놓아 앞에 붙인다. 쿼터니언 부호 연속·로컬 기준(첫 행 = 0)은 전체에 다시 적용.
  - 조각 시작이 크로스페이드 안이면 첫 월드 프레임이 블렌드 결과라 89→90 사이에 작은 차이가 날 수 있다(알려진 한계).

## 화면

- 클립 프리뷰 버튼: 꺼져 있으면 `기본자세 덧붙이기`, `기본자세 덮어쓰기`; 켜져 있으면 `기본자세 해제`.
- 결과 문구: "기본자세 덧붙이기를 켰습니다 (앞에 1.5초 추가 · 프리뷰·내보내기에만 적용)", "기본자세 덮어쓰기를 켰습니다 (앞 1.5초를 바꿈 · …)", "기본자세를 껐습니다".
- 트리 행·막대 표시: `기본자세` / `기본자세 덧붙임`.
- 물리 그래프: CSV 프레임 k ↔ 시퀀스 프레임 `from − 90 + k`(덧붙임). 막대 밖 부분은 잘려 보이지 않고, 경고 구간 클릭은 조각 시작 이후로 맞춘다. 내보내기 경고 프레임 번호도 같은 오프셋.

## 변경 (2026-10-12, 같은 날): 자르면 기본, 타임라인에도 반영

사용자: "자를 때 앞에 기본으로 기본자세가 되게끔", 잘라 보니 타임라인 재생에서 기본자세로 안 돌아감 → "조각 앞에 1.5초 자리 차지" 선택.

- 모션 트랙에서 자르면(C) 새로 생긴 뒤 조각은 `restPose: 'prepend'`. 앞 조각 표시는 그대로. 영상 조각은 해당 없음.
- 덧붙이기 90프레임은 **조각의 타임라인 길이에 포함**된다: `itemLen = trimOut − trimIn + restLead`, 클립 프레임 trimIn은 시퀀스 프레임 `start + 90`(`clipOrigin = start + restLead − trimIn`).
- 재생·클립 프리뷰·CSV가 모두 같은 프레임: `evaluate`가 `playable(p)`(기본자세 조각마다 파생 클립 `<clip>#rest:<item>`, 덧붙이기는 trimOut + 90)를 쓴다. CSV는 막대 범위를 그대로 샘플(별도 덧붙임 코드 없음). 덮어쓰기도 이제 타임라인 재생에 보인다.
- 덧붙이기를 켜고 끄거나 잘라서 뒤 조각이 생기면, 같은 트랙의 그 뒤 조각들이 ±90프레임 밀린다(상대 위치·크로스페이드 유지). 다른 트랙·영상은 움직이지 않는다.
- 자르기 위치가 리드인 안이면 자르지 않는다. 리드인 구간은 시퀀스 보기에서 편집 잠금(힌트 "기본자세 구간은 편집할 수 없습니다"), 클립 보기는 그대로 편집 가능.
- 막대: 리드인 구간을 옅은 강조색으로 칠함. 물리 그래프·경고 프레임: CSV 행 k = 시퀀스 프레임 `start + k`.
- 이전 한계(크로스페이드 안에서 시작하는 조각의 89→90 차이)는 없어짐: 크로스페이드는 리드인 구간에서 일어나고 리드인 끝 자세 = 첫 클립 프레임.
- 오늘 이전에 저장한 덧붙이기 조각이 있는 파일은 뒤 조각과 겹칠 수 있다(덧붙이기는 아직 배포 전이라 해당 없음).

## 기본자세 = 차렷 (2026-10-12)

사용자: "기본자세는 차렷한 자세 아니야? 손을 들고 있는데" — 관절 0은 G1 팔꿈치가 90°로 굽어 팔뚝이 앞으로 나간 자세였고, GO2는 종아리 0이 URDF 한계(−2.72 ~ −0.84) 밖이었다.

- `RobotDef.rest = { q, z }` (`loadRobot.ts`의 `REST`): G1 = 다리 곧게, 팔 차렷(팔꿈치 π/2 = 팔뚝 아래), 나머지 0. GO2 = Unitree 기본 서기(허벅지 앞 0.8·뒤 1.0, 종아리 −1.5, 엉덩이 0).
- `z`는 그 관절각으로 FK(축 회전 포함)해 가장 낮은 메시 점이 바닥에 닿는 루트 높이. `standingHeight`(관절 0)는 빈 채널의 root.z 기본값으로 그대로 둔다.
- 덮어쓰기·덧붙이기 모두 이 자세에서 시작.

## 이어지는 속도 맞춤 (2026-10-12)

사용자: "자르니까 기본자세에서 원래 하던 행동으로 갈 때 딜레이가 생긴다" — 블렌드가 첫 프레임 자세(정지)로 smoothstep해 끝에서 속도 0이 됐다가 90번째 프레임에서 원래 속도로 튀었다(걷기: 루트 0 → 0.5 m/s 한 프레임에).

- 관절·z·roll·pitch: 기본자세(속도 0) → 첫 프레임 값·기울기(클립 a→a+1)로 3차 Hermite. URDF 한계로 자름.
- x·y·yaw: 유지 위치를 첫 프레임보다 `블렌드 × 기울기 / 2` 뒤에 두고, 블렌드 동안 등가속(속도 0 → 첫 프레임 속도). 뒤로 물러나는 움직임 없음.
- 그래서 조각은 리드인 동안 그만큼 앞으로 이동해 도착한다(시퀀스 이어붙이기·`stitchTransforms`는 리드인 첫 자세 기준).
- 한계: 블렌드 1초 동안 몸은 가속하는데 다리는 걷는 동작으로 섞여 들어가므로 발이 약간 미끄러져 보일 수 있다.

## 되돌림: 메인 타임라인은 원본 (2026-10-12)

사용자: "기본자세는 클립에서만 나오게 할 수 있어? 메인 트랙에선 기본자세 안 했으면 좋겠어" → 위 "변경" 절의 타임라인 반영(리드인이 막대 길이에 포함·뒤 조각 밀림·`playable`·리드인 편집 잠금)을 되돌림.

- 유지: 자르면 뒤 조각 `'prepend'`(밀림 없음), 기본자세 = 차렷(`RobotDef.rest`), 리드인 끝 속도 맞춤.
- 기본자세는 클립 프리뷰와 그 조각의 CSV(와 그 CSV로 하는 물리 검증)에만. 메인 재생은 원본, 막대 길이도 원본.
- CSV 덧붙임 90행은 리드인 끝이 조각 첫 월드 프레임에 오도록 놓는다(x·y·yaw는 그 뒤에서 가속해 도착).

## 자르기 기본값 제거 (2026-10-12)

사용자: "자를 때 기본자세를 디폴트로 주지 말고 클립 프리뷰 내에서 설정할 수 있게 해 줘" → 자르기(C)는 `restPose`를 건드리지 않는다. 기본자세는 클립 프리뷰의 `기본자세 덧붙이기`/`기본자세 덮어쓰기`/`기본자세 해제` 버튼으로만 켜고 끈다.

## 클립 프리뷰 = 메인 재생헤드 따라감 (2026-10-12)

사용자: "프리뷰 클릭하면 계속 재생되는데, 프리뷰도 타임라인 움직이는 것처럼 똑같이 재생되게 해 줘" → 클립 프리뷰는 자체 시계 반복 대신 메인 재생헤드를 따른다(재생·정지·스크럽 동일).

- 프리뷰 프레임 = `range 시작 + clamp(재생헤드 − 조각 start, 0, 길이 − 1)`. 조각 시작에서 프리뷰는 range의 첫 프레임.
- 덧붙이기면 range 첫 프레임이 기본자세 리드인 시작이라, 프리뷰가 메인보다 1.5초 늦게 원래 모션을 보여 준다(조각 끝 1.5초는 재생헤드가 다음 조각으로 넘어간 동안 보임). 덮어쓰기·없음은 메인과 같은 프레임.
- 재생헤드가 조각 앞이면 첫 프레임, 뒤면 마지막 프레임에 멈춰 있다.
