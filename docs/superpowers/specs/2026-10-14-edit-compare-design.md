# 원본 · 수정본 분리 보기 (A안) 설계

날짜: 2026-10-14 · 상태: 초안 (사용자 선택: A안 "같은 조각에 수정 줄 추가") · 적용: `Desktop\robot` 합본
선행: `2026-10-13-piece-offset-design.md` (조각 수정 층)

## 문제

조각을 고치면(조각 수정 층) 메인 로봇 프리뷰·클립 프리뷰·시퀀스가 모두 수정된 모습만 보여 준다. 원본과 수정본을 나란히 비교할 수 없고,
시퀀스에서도 어느 조각이 고쳐졌는지, 재생·CSV에 무엇이 쓰이는지 분명하지 않다. 사용자 요청: "수정될 때는 로봇 프리뷰는 원본(수정되지
않은), 옆에는 클립 프리뷰가 아닌 수정 뷰로 원본이랑 분리되고, 시퀀스도 따로 분리".

## 결정

### 1. 데이터 — 조각마다 "쓸 쪽"

- `Item.use?: 'original'` 추가. 없으면 **수정본**(수정 층이 있을 때), 있으면 그 조각은 수정 층을 무시하고 **원본**으로 재생·내보내기.
- 수정 층(`Item.offset`)은 그대로 남는다 → 원본/수정본을 오가며 비교·결정할 수 있다. `수정 지우기`는 지금처럼 층을 지움.
- `itemClip(p, defs, it)`은 `it.use === 'original'`이면 원본 클립을 돌려준다 → 재생·CSV·물리·기본자세 리드인이 모두 같은 규칙(미리보기 = CSV)을 따른다.
- 새 함수 `editedClip(p, defs, it)`: `use`와 상관없이 원본 + 수정 층(수정본 보기·편집용).
- 저장: `items[].use`(값은 `'original'`만 허용). 실행취소 1번.

### 2. 시퀀스 — 수정 줄

- 수정 층에 키가 있는 조각은 그 조각 줄(레인) **바로 아래에 "수정" 줄**이 하나 더 생긴다. 트랙이 접혀 있어도(한 줄) 조각에 수정이 있으면 펼친다.
- 수정 줄: 같은 위치·길이의 막대를 `--piece` 색으로, 수정 키가 있는 클립 프레임 범위만 진하게, 나머지는 옅게. 라벨 `수정 · 키 n개`.
- 두 줄 중 **지금 쓰는 쪽**(재생·CSV)에 표시: 라벨 앞 `●`, 안 쓰는 쪽 막대는 반투명. 라벨의 `●` 자리를 누르거나 우클릭 메뉴 `원본 사용` / `수정본 사용`으로 바꾼다.
- 수정 줄 우클릭: `수정본 사용`, `원본 사용`, `수정 지우기`. 이동·트림·자르기는 원본 줄(조각)에서만 하고 수정 줄은 따라간다(같은 조각이므로).
- 물리 그래프·배지는 지금처럼 조각(쓰는 쪽)의 CSV 기준.

### 3. 화면 — 원본 | 수정본 비교

- **수정 비교 창**: 수정 층이 있는 조각에서 `수정 비교`를 열면(수정 줄 클릭, 클립 프리뷰의 `수정 비교` 버튼, 인스펙터 `이 조각 수정` 중 편집 시작) 클립 프리뷰 자리에 **수정본** 창이 열린다.
  - 제목: `수정본 · ■ G1 #1 / #n · 클립`. 그 조각의 원본 + 수정 층을 메인 재생헤드에 맞춰 보여 준다(클립 프리뷰와 같은 시간 규칙).
  - 이 창이 열려 있는 동안 **메인 로봇 프리뷰는 그 조각을 원본으로** 그린다(제목 옆 `원본` 표시). 다른 조각·다른 로봇은 평소대로.
  - 창 버튼 `겹쳐 보기`: 메인 화면에 수정본을 반투명 고스트로 함께 그린다(기본 꺼짐).
  - 창을 닫으면 메인은 다시 "쓰는 쪽"을 그린다.
- 수정 비교 창과 클립 프리뷰는 같은 자리를 쓴다(하나만). 수정이 없는 조각은 클립 프리뷰만.
- 인스펙터 값·키 편집은 지금처럼 `layer`를 따른다(`이 조각 수정` = 수정 층). 수정 비교 창이 열려 있으면 편집 결과가 오른쪽 창에 바로 보이고 왼쪽은 원본으로 유지된다.

## 범위 밖

- 여러 개의 수정본(버전), 원본/수정본 섞기 비율.
- 수정본을 새 클립으로 굽기(`수정을 클립에 적용`).
- 원본 저장소·Go2 작업트리 적용(조각 수정 층이 원본 저장소엔 없음). 필요하면 다음 단계.

## 완료 기준

- 수정한 조각: 시퀀스에 수정 줄, `●`로 쓰는 쪽 표시, 바꾸면 메인 재생·CSV·물리가 그쪽을 따름(단위 테스트: `use` 따라 CSV가 원본/수정본과 같음).
- 수정 비교 창: 같은 재생헤드에서 왼쪽(메인) = 원본 관절, 오른쪽 = 수정본 관절(e2e: 관절 피벗 비교). 닫으면 메인이 다시 쓰는 쪽.
- 저장·불러오기·실행취소.
