# 목록 패널 개편 (프리미어식 프로젝트 패널) 설계

날짜: 2026-10-16 · 브랜치 `feat/project-panel`(→ `smjeon`) · 대상: 왼쪽 목록 패널(`src/project/ProjectPanel.tsx`)

## 배경 (사용자 요청)

왼쪽 목록 패널을 프리미어 프로의 프로젝트 패널처럼 바꾼다. 1차 MVP:

1. 탭 `모션(CSV) | 영상 | 라이브러리`
2. 필터: 입력한 글자로 제목만 검색
3. 리소스를 폴더로 묶기
4. 폴더 때문에 프로젝트 생성 시 디스크 폴더를 지정해야 하는지 확인 → **필요 없음**(아래)

## 결정 사항

- **폴더 = 프로젝트 파일 안의 가상 폴더**(프리미어 Bin과 같음). 디스크 폴더를 만들거나 지정하지 않는다. 재생·CSV·물리·평가 코드는 바뀌지 않는다. 디스크 위치 지정은 데스크톱 앱 래핑 때 따로.
- 카드 보기를 없애고 **열이 있는 리스트 보기**로 바꾼다.
- 라이브러리 탭 = GO2 블록. 메뉴 `GO2 블럭 추가…`·`Go2BlockDialog`·인스펙터 GO2 블록 패널은 **없앤다**(사용자 확정).
- 폴더는 한 단계(중첩 없음), 탭마다 따로(모션 폴더 / 영상 폴더), 라이브러리에는 폴더 없음.
- 폴더 삭제 = 폴더만 지우고 안의 항목은 최상위로(클립이 시퀀스에서 쓰일 수 있어 안전한 쪽).

## 1. 레이아웃

```
┌ 목록 ───────────────────────────────┐
│ [모션(CSV)] [영상] [라이브러리]     │  탭 (role=tablist)
│ 🔍 [필터__________]        12 항목  │
│ 이름                  로봇  길이  사용│  열 머리
│ ▾ 📁 Walk                           │
│     ● walk_g1         G1  4.20s  2  │  ● = 클립 수정 층 있음
│       walk_turn       G1  3.00s  0  │
│ ▸ 📁 Jump                           │
│   track1              G1 210.6s  1  │
│─────────────────────────────────────│
│ [새 폴더]                  [⇄ 비교] │  아래 도구줄
└─────────────────────────────────────┘
```

탭별 열:

| 탭 | 열 | 도구줄 |
|---|---|---|
| 모션(CSV) | 이름 · 로봇 · 길이(초) · 사용(시퀀스 조각 수) | `새 폴더` · `⇄ 비교`(선택한 모션) |
| 영상 | 이름 · 길이 · 상태(오프라인이면 `다시 연결`) | `새 폴더` |
| 라이브러리 | 이름 · 종류(고정/거리/각도) | 없음(아래 블록 입력부) |

- 영상 탭 위쪽: 지금의 `보기 [오버레이][분할] 투명도`(V1에 영상이 있을 때만).
- 패널이 좁으면 `로봇`·`사용` 열을 먼저 숨긴다. 이름은 말줄임.
- 탭 선택·폴더 펼침은 화면 상태(저장 안 함). 가져오기 결과 메시지·삭제 거부 메시지는 지금처럼 패널 아래.

## 2. 줄 동작 (지금 카드 동작 유지)

- 클릭 = 선택(Ctrl/Shift 다중 선택은 폴더 이동·새 폴더용), 끌기 = 타임라인 배치(`setDragged`/`application/x-motion-clip`·`-media` 그대로).
- 모션 줄 더블클릭 = 클립 편집(`openClipEdit`), 폴더 줄 더블클릭 = 펼치기/접기.
- Enter/F2 = 이름 변경(모션·폴더), Delete = 삭제(시퀀스에서 쓰는 클립·영상은 지금처럼 거부 메시지).
- 우클릭(또는 ContextMenu/Shift+F10): 모션 `클립 편집 · 이름 변경 · 폴더로 이동 ▸ · 삭제`, 영상 `폴더로 이동 ▸ · 삭제`(영상 이름 변경은 지금도 없음 — 범위 밖), 폴더 `이름 변경 · 삭제`.
- ↑/↓ 줄 이동, ←/→ 폴더 접기/펼치기(트리 키보드).
- CSV 파일을 패널 어디에 놓아도 가져오기(`importDroppedFiles`, 지금과 같음).

## 3. 필터

- 지금 탭의 항목 이름에 입력 글자가 들어 있으면 표시(대소문자 무시, 앞뒤 공백 무시). 폴더 이름은 검색 대상 아님.
- 필터 중: 일치 항목이 있는 폴더만 보이고 자동 펼침, 빈 폴더 숨김. 오른쪽 `n 항목` = 보이는 항목 수(폴더 제외).
- 탭을 바꿔도 필터 글자는 유지.
- 순수 함수 `filterTree(items, bins, query, open)` → 표시할 줄 목록(폴더 줄·항목 줄·들여쓰기). 단위 테스트 대상.

## 4. 폴더

데이터(프로젝트 파일에 저장, 모두 선택 필드):

```ts
interface Bin { id: string; name: string; tab: 'clip' | 'media' }
Project.bins?: Bin[]      // 표시 순서 = 배열 순서
Clip.bin?: string         // 폴더 id, 없으면 최상위
Media.bin?: string
```

- 옛 파일: 필드 없음 → 모두 최상위.
- 파일 읽기 검증(`projectFile.ts`): `bins`가 배열이 아니거나 항목 모양(id·name 문자열, tab 값)이 틀리면 거부(다른 필드와 같은 규칙). 없는 폴더를 가리키거나 탭이 맞지 않는 `bin`은 **지우고 최상위로**(거부하지 않음). 중복 폴더 id는 거부.
- 만들기: `새 폴더` → `폴더 1`(겹치면 `폴더 2`…), 바로 이름 입력 상태, 펼친 채. 선택 항목이 있으면 그 항목들이 새 폴더로 들어감(프리미어).
- 옮기기: 줄을 패널 안 폴더 줄에 놓으면 그 폴더로, 폴더 밖 빈 곳/최상위 항목 위에 놓으면 최상위로. 우클릭 `폴더로 이동 ▸ (최상위) / 폴더 이름…`. 타임라인에 놓으면 지금처럼 배치(놓는 곳으로 구분).
- 이름 변경: 빈 이름은 취소. 같은 이름 허용(프리미어와 같음).
- 삭제: 폴더만 지움, 안의 항목 `bin` 제거 → 최상위. 확인 창 없음.
- 스토어 액션(각각 실행취소 1회·dirty): `addBin(tab, name, ids?) → id`, `renameBin(id, name)`, `deleteBin(id)`, `moveToBin(ids, binId | null)`. 클립 이동은 `touched` 없이 클립 객체만 새로 만든다(채널은 공유, 수정 층 캐시 키 유지).
- 클립 삭제·가져오기는 그대로(새로 가져온 클립은 최상위).

## 5. 라이브러리 탭 (GO2 블록)

```
│ 이름                      종류    │
│   Move forward            거리    │
│   Rotate                  각도    │
│   Stretch                 고정    │ …15개
│───────────────────────────────────│
│ Move forward                      │  고른 블록
│ 거리 [1.0] m   → 실제 1.24m (2회) │
│ 대상: GO2 #1            [추가]    │
```

- 목록 = `GO2_BLOCKS`. 필터 적용(블록 이름).
- 고른 블록의 입력부 = 지금 `Go2BlockPanel` 재사용(블록 선택 `<select>` 대신 목록 선택을 받도록 `blockId` prop). 템플릿 불러오기·실제 값 미리보기·오류 표시 그대로.
- 대상: 선택한 액터가 GO2면 그 액터, 아니면 첫 GO2 액터, 없으면 새 GO2 액터(`appendClip(null, …)`, 지금 메뉴 동작). 대상 트랙이 잠기면 `추가` 비활성.
- 고정 블록 13개는 타임라인으로 끌어 놓기 가능: GO2 트랙 위면 그 위치(에셋 드롭 규칙: 겹치면 뒤에 붙임), 빈 곳이면 새 GO2 액터. 거리·각도 블록은 `추가`로만. 끌기 데이터 `application/x-motion-block`, 놓을 때 템플릿을 불러와 클립 생성(`buildBlockClip`) 후 기존 클립 드롭과 같은 배치.
- 만든 클립은 모션 탭 목록에도 생김(지금과 같음).

## 8. 테스트

- 단위: `projectFile`(폴더 왕복, 옛 파일, 없는 폴더·탭 불일치 정리, 잘못된 bins 거부), 스토어(만들기·이름 변경·이동·삭제→최상위, 실행취소 1회, 새 폴더에 선택 항목), `binTree`(필터·자동 펼침·빈 폴더 숨김·항목 수).
- e2e 새 `projectPanel.spec`: 탭 전환·필터·새 폴더·끌어서 넣기·저장 후 다시 열기·폴더 삭제·줄→타임라인 끌기·더블클릭 클립 편집·라이브러리 추가와 고정 블록 끌어 놓기.
- e2e 고칠 것: `go2blocks.spec`(라이브러리 탭으로), `import.spec` 메뉴 항목 수, 카드 선택자를 쓰는 spec(`drop`·`compare`·`clipEdit`·`csvDrop`·`video` 등).

## 9. MVP에서 뺀 것
