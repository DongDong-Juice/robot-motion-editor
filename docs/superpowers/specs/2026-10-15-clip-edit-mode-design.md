# 클립 편집 모드 · 떠 있는 관절 패널 · 구간 수정 설계

날짜: 2026-10-15 · 적용: `Desktop\robot` 합본 · 기준 로봇: G1(GO2도 같은 코드로 동작)

## 배경 (사용자 요청)

G1 CSV를 고칠 때 시퀀스를 거치는 것이 불편하다.

1. 클립 하나를 고치려 해도 시퀀스에 조각을 놓고 → 더블클릭(클립 보기) → 고치고 → 시퀀스로 돌아가야 한다.
2. 타임라인(아래)에서 관절을 고르고, 오른쪽 인스펙터 맨 아래 `값`까지 올라가서 슬라이더를 움직여야 한다.
3. 가져온 CSV는 매 프레임이 키라서 `원본 클립 수정`으로 한 프레임만 고치면 그 프레임만 튄다. 구간 단위로 부드럽게 고칠 방법이 없다.

## 사용자 결정 (2026-10-15)

- 관절 값 편집 위치 = **3D 화면 위 떠 있는 패널**.
- 클립 편집 모드 = **목록에서 더블클릭으로 들어가고, 수정은 수정 층에 저장**(원본은 그대로).
- 튀는 문제 = **구간 선택 + 부드러운 가감**.

## 1. 클립 편집 모드

### 들어가기·나가기

- 목록 패널의 클립 카드를 **더블클릭**하면 클립 편집 모드로 들어간다. 지금 카드 더블클릭 = 이름 바꾸기는 **이름 글자 더블클릭**과 우클릭 `이름 바꾸기`로 옮긴다.
- 카드 우클릭 메뉴에 `클립 편집`을 추가한다.
- 타임라인 머리줄 경로: `목록 ▸ <클립 이름> (클립 편집)`. `시퀀스로` 버튼 또는 Esc로 나간다(텍스트 입력 중 Esc는 제외).
- 편집기 상태 `clipEdit: string | null`(클립 ID, 저장 안 함). 열려 있는 동안 `editing`(시퀀스 클립 보기)은 `null`이다.

### 화면

- **메인 3D**: 그 클립만 그린다. 원점에 서고, 로봇 색은 G1 `#58B4D1` / GO2 `#C9D65A`. 시퀀스의 다른 액터·영상은 그리지 않는다.
- **타임라인**: 클립 프레임 축. 지금의 클립 보기와 같은 `트랙`/`그래프` 보기를 쓴다(키 선택·이동·복사/붙여넣기·그래프 편집 그대로). 재생 범위 = 클립 0 … length-1.
- **인스펙터**: 액터 칸(색·배치) 대신 클립 칸(이름·길이·키 줄이기)과 편집 대상만 보인다. 편집 대상 버튼은 `이 클립 수정`(기본) / `원본 클립 수정`.
- 클립 프리뷰·비교 창은 닫지 않고 그대로 둔다(메인 재생헤드를 따르지 않음 — 클립 편집 중에는 멈춰 있음).

### 수정 층 (에셋 단위)

- 새 필드 `Clip.offset?: Record<채널, Curve>` = **클립 수정 층**. 조각 수정 층(`Item.offset`)과 같은 형식: 클립 프레임 기준 차이값, 저장은 v2 압축 형식(`{ k: [...] }`), 읽을 때 채널 이름 검증.
- `baseClip(p, defs, clipId)` = 원본 + 클립 수정 층(관절 한계로 자름, `bakeOffset` 재사용, 메모). 수정 층이 없으면 원본 그대로.
- **시퀀스 조각은 `baseClip` 위에 조각 수정 층을 더한다**: `editedClip`·`itemClip`이 `p.clips[it.refId]` 대신 `baseClip`을 쓴다. 즉 클립 편집 모드에서 고친 내용은 그 클립을 쓰는 모든 조각에 반영된다(에셋 자체를 고친 것). 조각 `원본 사용`(`Item.use`)은 지금처럼 **조각 수정 층만** 뺀다.
- 원본 비교: 클립 편집 모드 머리줄에 `원본 보기`(누르고 있는 동안 메인이 원본) 와 `겹쳐 보기`(원본 고스트, 기존 `OVERLAY` 색) 버튼. 인스펙터에 `수정 키 n개` · `수정 지우기`.
- 목록 카드: 클립 수정 층이 있으면 이름 앞에 `●` 표시와 툴팁 "수정됨 · 수정 키 n개".
- 시퀀스 편집 대상 버튼에 `원본 클립 수정`을 고르면 지금처럼 원본 클립을 직접 고친다(자동 키 필요). 클립 편집 모드의 `원본 클립 수정`도 같다.

### CSV 저장

- 클립 편집 모드 머리줄에 `CSV 저장` 버튼. `baseClip`을 그대로 내보낸다(기본자세·리드인 없음, 루트 = 로컬, 파일 이름 = `<G1|GO2>_<클립 이름>.csv`). 저장 후 "CSV를 저장했습니다".
- 파일 API는 `src/fileio.ts`만 쓴다. 미리보기 = CSV: 메인 3D와 CSV가 같은 `baseClip`을 평가한다.

## 2. 떠 있는 관절 패널

- 메인 3D 패널 오른쪽 위에 뜨는 패널. **시퀀스·시퀀스 클립 보기·클립 편집 모드 모두**에서 쓴다.
- 관절(또는 루트)을 고르면(3D 클릭·트랙 줄 클릭·그래프) 나타나고, 그 관절이 속한 **부위 전체**(예: 왼다리 6관절, 루트 6채널)의 줄을 보여 준다. 고른 관절 줄은 `--accent`로 강조. 다른 줄을 눌러 바로 바꿀 수 있다(다시 고르지 않아도 됨).
- 줄 = 관절 이름 · 슬라이더 · 숫자(도/rad 전환은 인스펙터와 공유) · 한계 근처 표시. 동작은 인스펙터 `값`과 같다(같은 `setValue`·제스처 실행취소·잠금 규칙·자동 키 규칙).
- 아래쪽 도구: `◀ 이전 키` `▶ 다음 키` `키 추가` `키 삭제`, 그리고 **구간** 줄(3장).
- 패널 머리: 부위 이름 · `─` 접기 · `✕` 닫기(선택 해제). 접힘 상태는 `localStorage`(try/catch). 패널은 3D 위 오른쪽 위에 고정, 드래그 이동 없음(범위 밖).
- 키보드: 패널에 포커스가 있을 때 ↑/↓ = 위/아래 관절, ←/→ = 값 미세 조정(0.5° / 루트 0.005 m), Shift = 10배.
- 인스펙터 `값` 칸은 그대로 둔다(같은 상태를 보여 줌).
- 클립 프리뷰·비교 창 같은 다른 3D 창에는 패널이 없다.

## 3. 구간 수정

- 클립 축 타임라인(시퀀스 클립 보기, 클립 편집 모드)에서 **눈금자를 Shift+드래그**하면 구간 `[a, b]`(클립 프레임)를 고른다. 그냥 드래그는 지금처럼 재생헤드 이동. 구간은 눈금자와 키 영역에 반투명 띠로 그리고, 앞뒤 가감 구간은 더 옅은 띠.
- 떠 있는 패널 **구간** 줄: `구간 a – b` 숫자 입력 두 개, `가감 n프레임`(기본 15), `✕ 구간 해제`. 구간이 없으면 `Shift+드래그로 구간 선택` 안내만.
- 편집기 상태 `range: { a: number; b: number; fade: number } | null`(저장 안 함). 열린 클립이 바뀌면 해제.
- **구간이 있을 때** 슬라이더·숫자·기즈모로 값을 바꾸면: 재생헤드 프레임에서의 차이 `d = 새 값 − 지금 값`을 구간 전체에 더한다.
  - 가중치 `w(f)` = 구간 안 1, 앞뒤 `fade` 프레임 동안 smoothstep으로 0까지, 그 밖 0.
  - 편집 대상(클립 수정 층 / 조각 수정 층 / 원본 클립)의 해당 채널을 `[a − fade, b + fade]`에서 프레임마다 `기존 + d·w(f)` 선형 키로 다시 쓴다. 그 밖의 값은 바뀌지 않게 경계 바깥 첫 프레임에 기존 값 키를 남긴다.
  - 관절은 결과가 URDF 한계를 넘지 않게 자른다(수정 층은 `bakeOffset`이 자르고, 원본 클립은 직접 자름).
  - 한 번의 드래그(제스처)는 실행취소 1번. 드래그 중 `d`는 제스처 시작 값 기준으로 다시 계산(누적 오차 없음).
  - 재생헤드가 구간 밖이면 값 편집을 막고 "재생헤드를 구간 안으로 옮기세요" 표시.
- **구간이 없을 때**는 지금과 같다(그 프레임에 키).
- 시퀀스 보기(시간 축 = 시퀀스)에서는 구간 선택을 하지 않는다.

## 테스트

- 단위: `baseClip`(수정 없음 = 원본, 있으면 원본 + 수정·한계), `itemClip` = baseClip + 조각 수정, `use: 'original'`은 조각 수정만 뺌, 프로젝트 `clips[].offset` 왕복·거부, 구간 가중치(경계·fade 0·클립 끝 넘침), 구간 쓰기 후 구간 밖 값 불변, 제스처 실행취소 1번.
- e2e:
  - 목록 더블클릭 → 클립 편집 모드, 슬라이더(떠 있는 패널)로 수정 → `CSV 저장` 결과 = 메인 포즈, 원본 클립 곡선 불변, 시퀀스 조각도 수정 반영.
  - 3D에서 관절 클릭 → 떠 있는 패널에 그 부위, 다른 줄 클릭으로 관절 바꿔 편집.
  - Shift+드래그로 구간 → 값 변경 → 구간 안 같은 차이, fade 밖 원본, 이음매 속도 한계 위반 없음.
- 기존 `leadIn.sweep`·`restTail.sweep` 통과 유지(리드인이 `itemClip`을 쓰므로).

## 범위 밖

- 패널 드래그 이동·여러 부위 동시 표시, IK 드래그(손·발 끌기), 부드럽게 하기 필터, 좌우 대칭, 속도 바꾸기, 포즈 복사/붙여넣기, 어니언 스킨 — 다음 단계 후보.
- 클립 수정 층을 원본에 굽기(`수정을 클립에 적용`).
