# 원본 · 수정본 분리 보기 (A안) 구현 계획

스펙: `docs/superpowers/specs/2026-10-14-edit-compare-design.md` · 적용: `Desktop\robot` 합본 (커밋은 요청 시)

## 1. 모델·저장

- [x] 1. `types.ts` `Item.use?: 'original'`; `projectFile` 검증·저장(+테스트: 왕복, 잘못된 값 거부)
- [x] 2. `itemClip`: `use === 'original'`이면 원본; `editedClip`(항상 원본 + 수정) 추가 (+테스트: CSV가 `use`에 따라 원본/수정본과 같음, 물리 키도 바뀜)
- [x] 3. 스토어 `setItemUse(itemId, 'original' | null)`(잠금 거부, 실행취소 1) · `editCompare: string | null`(조각 ID, 저장 안 함) `openEditCompare`/`closeEditCompare`, 조각이 사라지거나 수정이 지워지면 닫힘 (+테스트)

## 2. 시퀀스

- [x] 4. 레이아웃: 수정 키가 있는 조각 레인 아래 `수정` 행(`Row.edit`), 그런 조각이 있으면 트랙 자동 펼침
- [x] 5. 그리기: 수정 막대(`--piece`, 수정 키 범위 진하게), 쓰는 쪽 `●`, 안 쓰는 쪽 반투명, 라벨 `수정 · 키 n개`
- [x] 6. 입력: `●` 클릭 = 쓰는 쪽 전환, 수정 행 클릭 = 수정 비교 열기, 우클릭 메뉴(수정본 사용 / 원본 사용 / 수정 지우기); 수정 행은 이동·트림 없음
- [x] 7. sr-only 버튼(접근성): `{조각} 수정본 사용`, `{조각} 수정 비교`

## 3. 화면

- [x] 8. `StagePanes`: 클립 프리뷰 자리에 `EditCompare` 창(제목 `수정본 · …`, `겹쳐 보기`, 닫기), 클립 프리뷰에 `수정 비교` 버튼(수정이 있을 때)
- [x] 9. `Stage`: 수정본 창 = `editedClip` + 클립 프리뷰와 같은 시간 규칙; 메인 = `editCompare` 조각을 원본으로(평가 시 그 조각만 `use: 'original'` 취급한 프로젝트 사본), 제목 `원본` 표시; 겹쳐 보기 고스트 리그
- [x] 10. 인스펙터: `이 조각 수정`으로 처음 키를 만들면 수정 비교 자동 열기(옵션 아님, 이미 다른 창이 열려 있으면 그대로)

## 4. 확인·문서

- [x] 11. e2e `editCompare.spec.ts`: 수정 → 수정 줄·● 표시 → 비교 창에서 메인=원본·창=수정본 관절 비교 → 원본 사용으로 바꾸면 CSV 원본과 같음 → 닫으면 메인=쓰는 쪽; 저장·불러오기
- [x] 12. 단위·tsc·e2e 전체 통과, CLAUDE.md(합본) 갱신, 화면 캡처 확인

## 위험

- `itemClip`을 쓰는 곳이 많다(평가·CSV·리드인·인스펙터·그래프). 편집 화면(인스펙터·그래프·트랙 보기)은 `use`와 상관없이 수정본을 보여 줘야 하므로 `editedClip`으로 바꿔야 하는 곳을 빠짐없이 확인.
- 메인을 "그 조각만 원본"으로 그릴 때 루트 이어붙이기(`stitchTransforms`)가 다음 조각 위치에 영향 → 비교 중에는 메인 전체가 원본 기준으로 이어질 수 있음(스펙에 명시, 비교 창 닫으면 복귀).
