# 배치 이동 · GO2 걸어가기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메인 3D 끌기를 배치(Actor.placement) 이동으로 바꾸고, `배치 이동` 토글이 켜지면 GO2를 끌어 놓은 지점까지 걷는 클립을 실제 로그로 만들어 트랙 끝에 붙인다.

**Architecture:** 순수 함수 `go2blocks/walkTo.ts`(Rotate·Move 템플릿 포즈 → 정확한 도착 걷기 클립)를 Stage의 끌기 처리가 부른다. 토글은 스토어 UI 필드 `walkMode`. 클립 배치는 기존 `appendClip`(tryEdit 1회 = 실행취소 1번, 트랙 끝 이어 붙이기).

**Tech Stack:** React 19, TypeScript, three.js, zustand, vitest, Playwright

**Spec:** `docs/superpowers/specs/2026-10-20-go2-walk-to-design.md`

## Global Constraints

- 토글 꺼짐 끌기 = `setPlacement(actorId, { x, y })`(G1·GO2), 키·수정 층 없음, 끌기 1회 = 실행취소 1번. 기존 `editPose` 끌기 제거.
- 끌기 시작 안 함: `trackLocked`, 숨김(`offStage`), `s.clipEdit`, `s.playing`. 클릭(4 px 안) = 관절 선택, 빈 곳 = 카메라, 기즈모 = 기즈모, 끄는 중 Ctrl+Z = 그 끌기만 취소.
- 토글 `배치 이동`: `pv-tools`에서 `무대` 바로 뒤, 메인 창만, 스토어 `walkMode`(기본 false, 저장 안 함). 켜면 재생헤드 = 선택된 GO2(없으면 첫 GO2) 트랙 끝 − 1.
- 토글 켜짐 + GO2 끌기: 로봇 고정, 출발점→커서 `--accent` 점선 + 도착 원, 놓으면 `walkToClip` → `appendClip`, 재생헤드 = 새 트랙 끝 − 1. G1은 배치 이동.
- 걷기: |θ| ≥ 60° = Rotate 제자리 회전(yaw를 θ/실제 배) 후 Move 걷기; |θ| < 60° = 걷기 head 구간 동안 yaw 0→θ smoothstep. Move 진행 성분 배율 [0.8, 1.2]; 안 되면 `이 거리는 너무 가깝습니다 (최소 약 X m)`(X = 최소 걷기 거리 × 0.8, 소수 1자리), 클립 안 만듦, `seqFlash`로 안내.
- 클립: 첫 프레임 원점·yaw 0, 마지막 루트 = (d cos θ, d sin θ)·방향 θ, 이름 `Walk_<d .1f>m_<θ 정수>deg`, 60 fps, `go2`.
- UI 한국어, 색 토큰, 3D 리소스 dispose. 작업 중엔 관련 테스트만.
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. 뒤쪽(θ ≈ 180°)·정확히 −60°/60° 경계 → 회전 방식 선택이 일관되고 도착 오차 < 1 cm (Task 1 테스트에 ±60°, 180°, −179°).
2. 트랙이 빈 GO2 / 트랙 잠김 GO2에 걷기 → 빈 트랙: 배치 위치에서 출발해 0프레임부터, 잠김: 아무것도 안 만들고 안내 (Task 3 e2e).
3. 토글 켜고 끄는 중 Ctrl+Z → 클립 안 생김, 점선 사라짐 (Task 3 e2e).
4. 템플릿(CSV) 아직 로딩 중에 놓음 → 로딩 후 만들거나 안내, 오류 없음 (Task 3: 토글 켤 때 미리 로드, 놓을 때 await).
5. 배치 끌기 후 G1 CSV(로컬 루트) 내용 불변 (Task 2 단위: exportItemCsv local 동일).
