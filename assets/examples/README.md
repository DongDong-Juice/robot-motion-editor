# 테스트용 예제 파일

`node tools/make_examples.mjs`로 만든 합성 모션입니다. 발 디딤을 먼저 정하고(디딘 발은 고정, 드는 발은 포물선) 다리 관절을 URDF 역기구학(IK)으로 풀어서, 디딘 발이 미끄러지지 않습니다(프레임당 0.3 mm 이하). 다만 균형(무게중심)까지 계산한 모션은 아니라서 물리 보조력은 높게 나올 수 있습니다.

| 파일 | 가져오는 방법 | 확인할 것 |
|---|---|---|
| `examples.mproj` | 메뉴 ▸ 열기 | 아래 "프로젝트" 참고 |
| `g1_walk.csv` | CSV 가져오기 | G1 걷기 3.5초(210프레임, 왼발부터 6걸음 + 마무리), 헤더 있음 |
| `g1_wave.csv` | CSV 가져오기 | G1 오른팔 흔들기 3초(180프레임) |
| `g1_turn_30fps.csv` | CSV 가져오기 | 헤더 fps 30 → 60으로 리샘플(126행 → 251프레임), 제자리에서 발을 옮기며 90° 회전 |
| `g1_squat_headless.csv` | CSV 가져오기 → **30fps** 선택 | 헤더 없는 36열 형식, fps 선택 창. 발 고정 스쿼트 |
| `go2_trot.csv` | CSV 가져오기 | GO2 트롯 3.5초(대각선 다리 쌍), 헤더 있음(RobotType 1) |
| `go2_sit_headless.csv` | CSV 가져오기 → **60fps** 선택 | 헤더 없는 19열 GO2 형식. 발 고정, 몸 숙였다 일어나기 |
| `g1_warnings.csv` | CSV 가져오기 → 내보내기 | 경고 2종: `right_elbow_joint` 한계 초과, 120프레임 루트 점프(0.2 m) |
| `error_robot_type.csv` | CSV 가져오기 | 가져오기 거부: "RobotType(1)과 DOF Number(29)가 맞지 않습니다" |

여러 파일을 한 번에 골라도 됩니다. 오류 파일만 빠지고 나머지는 들어옵니다.

## 프로젝트 (`examples.mproj`)

- **G1 #1** 트랙
  - `walk`를 클립 105프레임에서 자른 두 조각. 내보내면 `G1_walk_1.csv`, `G1_walk_2.csv`.
  - 첫 조각은 **기본자세 덧붙이기**: CSV 앞에 기본자세 1.5초가 붙어 195행(105 + 90)입니다. 메인 타임라인은 원본 그대로 재생합니다. 기본자세는 클립 프리뷰의 버튼으로 켜고 끕니다.
  - `wave`는 두 번째 조각과 20프레임 겹칩니다(크로스페이드, 190~210프레임).
- **GO2 #1** 트랙: `trot` 3.5초. 배치 y = 1.5 m.
- 105프레임에 마커 `자른 곳`.

해 볼 것:
- 트리를 펼치고 조각을 눌러 클립 프리뷰를 엽니다. 리드인 설정 줄의 `기본자세 덧붙이기` 스위치를 켜고 꺼 봅니다.
- 막대를 우클릭해 `물리 검증`을 실행합니다.
- 트리에서 조각을 눌러 클립 프리뷰를 열면 차렷자세로 섰다가 모션으로 이어지는 것을 볼 수 있습니다.
- 조각을 드래그하는 중에 Ctrl+Z를 누르면 그 드래그만 취소됩니다.
- 메뉴 ▸ 내보내기로 파일 이름과 행 수를 확인합니다.

## 기본자세 덧붙이기

클립 프리뷰 아래 리드인 설정 줄의 `기본자세 덧붙이기` 스위치로 켭니다. 스위치에 마우스를 올리면 같은 설명이 나옵니다. 조각 앞에 차렷자세에서 시작하는 리드인(기본자세 정지 → 전이 → 관성)을 붙여 CSV가 그만큼 길어지고, 원래 모션은 그대로입니다. 클립 프리뷰와 그 조각의 CSV에만 적용됩니다(메인 타임라인은 원본).
